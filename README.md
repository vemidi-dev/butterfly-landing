# Вълшебни пеперуди — VeMiDi crafts

Landing page за творческия комплект „Вълшебни пеперуди“ на български език.

## Стартиране

Отвори `index.html` в браузър или стартирай локален сървър:

```bash
npx serve .
```

## Замяна на снимки

В `index.html` потърси коментарите `Replace src` и смени `src` на:

- Hero: `.hero__image`
- Варианти: `.variant-card__image img`
- Секция 1 юни: `.june__visual img`

Логото е в `assets/logo.png`.

## Конфигуратор

- Избор на размер (Малки / Големи) с автоматична цена
- Бои или флумастери
- Персонализация с име (+2,50 €)
- Динамично обобщение и обща цена
- Валидация при поръчка (име / послание)

## Файлове

- `index.html` — структура и съдържание
- `styles.css` — визуална идентичност и responsive layout
- `script.js` — конфигуратор, цени и модал за поръчка
- `assets/logo.png` — официално лого
